RGBControl for Windows
======================

1. Extract the entire ZIP file to a local folder.
2. Double-click install_service.bat and accept the Windows administrator prompt.
3. Open RGB Control from the Start menu and choose a dynamic theme.

The Windows service starts with your PC. The app and service use the same
RGBControl.exe in Program Files. You do not need Python or OpenRGB.

To remove the service and app, double-click uninstall_service.bat from the
extracted folder. Your theme settings remain in ProgramData\RGBControl.

This release supports the Gigabyte RGB Fusion 2 USB HID controller with
hardware ID 048D:5702. It was tested with an IT5701-GIGABYTE controller on
a B760M Gaming Plus WiFi DDR4 motherboard. Other hardware is untested.

More information is in the repository README.md.
